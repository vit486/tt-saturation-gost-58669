# ⚡ Проверка трансформаторов тока (насыщение при КЗ)

Веб-приложение для проверки и выбора трансформаторов тока (ТТ) для релейной
защиты по **ГОСТ Р 58669-2019**:

- **аналитический метод** (раздел 5.1) — формулы (3)/(6), (9)–(11);
- **графический метод по паспортным данным** (раздел 5.2) — численный
  эквивалент универсальных характеристик приложения Б: кривые K_п.р(t) по
  формуле (Г.15) с подбором наихудшей начальной фазы θ, динамические графики;
- автоматическая самопроверка по эталонным примерам стандарта
  (Приложения В и Б, с учётом Поправки ИУС 6–7, 2020);
- отчёт в Word.

Разворачивается на Streamlit Community Cloud прямо из этого репозитория.

**Текущий релиз: 1.3 (22.10.2026)** — графический метод с динамическими графиками.

## Главные формулы

Время до насыщения, формулы (3)/(6) ГОСТ Р 58669-2019:
t_нас = T_p · ln( ω·T_p / (ω·T_p + 1 − A·(1 − K_r)) )

> \*\*Важно:\*\* «+1» присутствует \*\*только в знаменателе\*\*.
> Контрольный пример стандарта (Приложение В, п. В.1.1.8):
> `t(3) = 0,128 · ln( 314·0,128 / (314·0,128 − 5,785 + 1) ) = 16,22 мс`

Параметр режима (формула 9):
A = ( I1ном · Kном · z2Σном ) / ( Iкз · z2Σ )

Графический метод: время до насыщения из решения `K\_п.р(t\_нас) = A·(1 − K\_r)`
при наихудшей начальной фазе θ; K_п.р(t) — по формуле (Г.15).

## История релизов

- **1.3** — графический метод по паспортным данным (п. 5.2): численный
  эквивалент универсальных характеристик, динамические графики, пример В.2.1

  файлов.
- **1.1** — исправлена формула времени до насыщения (числитель ω·T_p вместо
  ω·T_p+1), добавлена самопроверка по эталонным примерам Приложения В.
- **1.0** — аналитический метод, отчёт в Word.

## Нормативная база

- ГОСТ Р 58669-2019 (+ Поправка ИУС 6–7, 2020) — время до насыщения, классы P/PX/TPX;
- ГОСТ Р 71879-2024 — время до насыщения, классы 5PR/10PR/TPY/TPZ/TPE, циклы АПВ;
- ГОСТ Р 71403-2024 — методика выбора ТТ;
- ГОСТ Р 70507.1-2024, ГОСТ Р 70507.2-2024 — общие ТУ на трансформаторы тока;
- ГОСТ 7746-2015 — ТУ на ТТ прежних выпусков;
- РД 153-34.0-35.301-2002 — проверка эксплуатируемых ТТ (все классы напряжения);
- ПУЭ — требования к выбору и применению ТТ.
