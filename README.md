# ⚡ Проверка трансформаторов тока (насыщение при КЗ)

Веб-приложение для проверки и выбора трансформаторов тока (ТТ) для релейной защиты:
расчёт времени до насыщения при коротких замыканиях по **ГОСТ Р 58669-2019**
с автоматической самопроверкой по эталонным примерам стандарта, динамическими
графиками и формированием отчёта в Word (с графиками).

Разворачивается на Streamlit Community Cloud прямо из этого репозитория.

**Текущий релиз: 1.5 (23.10.2026)** — нагрузка вторичной цепи рассчитывается
из параметров всей цепи: приборы + кабель (материал, длина, сечение, схема) + контакты.

## Нагрузка вторичной цепи (п. 4.2.6, Приложение А)

Фактическая нагрузка ТТ формируется из параметров всей вторичной цепи:
Rн.факт = Rприб + Rпер + Rкаб
Rкаб    = ρ · kсх · L / S

- ρ при 20 °С (п. 4.2.1, ГОСТ 15150): медь 0,0175; алюминий 0,0281 Ом·мм²/м;
- L — длина кабеля в одну сторону, м; S — сечение жилы, мм²;
- Rпер — переходное сопротивление контактов: 0,05 или 0,1 Ом;
- kсх — коэффициент расчётной длины (зависит от схемы и вида КЗ):

| Схема | Трёхфазное КЗ | Однофазное КЗ |
|---|---|---|
| Полная звезда (3 ТТ) | 1 | 2 |
| Неполная звезда (2 ТТ) | √3 ≈ 1,73 | 2 |
| Один ТТ (2 провода) | 2 | 2 |

Для трёхфазного и однофазного КЗ сопротивление кабеля различается, поэтому
нагрузка рассчитывается отдельно для каждого вида КЗ.

**Начальная фаза θ** в графическом методе по умолчанию находится автоматически как
наихудшая (минимум t_нас, п. Г.3.7); при необходимости задаётся вручную
(чек-бокс в панели слева).

## Главные формулы

Оба метода решают одно уравнение переходного процесса (п. Г.6.2):
A·(1 − K_r) = K_п.р(t_нас)

**Параметр режима A** (формула 9):
A = ( I1ном · Kном · z2Σном ) / ( Iкз · z2Σ )
zн.ном = Sном / I2ном²
z2Σном = √( (R2 + zн.ном·cos φном)² + (X2 + zн.ном·sin φном)² )        (10)
z2Σ    = √( (R2 + Rн.факт)² + (X2 + Xн.факт)² )                        (11)
cos α  = ( R2 + Rн.факт ) / z2Σ                                        (12)

**Аналитический метод** — формулы (3)/(6):
t_нас = T_p · ln( ω·T_p / ( ω·T_p + 1 − A·(1 − K_r) ) )

> **Важно:** «+1» присутствует **только в знаменателе**.
> Контрольный пример стандарта (Приложение В, п. В.1.1.8):
> `t(3) = 0,128 · ln( 314·0,128 / ( 314·0,128 − 5,785 + 1 ) ) = 16,22 мс`

**Графический метод** — коэффициент переходного режима по формуле (Г.15):
K_п.р(t) = sin α · cos θ · e^(−t/T_p)
         + cos α · cos θ · ω·T_p · ( 1 − e^(−t/T_p) )
         − sin( ω·t + α + θ ) + cos α · sin θ
t_нас:  K_п.р(t_нас) = A·(1 − K_r),  минимум по θ ∈ (−90°, +90°)

## Достоверность расчётов

Расчётное ядро проверяется автоматически (вкладка «🧪 Самопроверка»):

1. **Аналитический метод** — воспроизведение эталонных примеров ГОСТ Р 58669-2019
   (Приложение В, В.1.1–В.1.3, с учётом Поправки ИУС 6–7, 2020) — 6 строк, все ✅.
2. **Графический метод** — 8 проверок реализации формулы (Г.15): начальное условие
   K(0) = 0; вырождение в (Г.17)/(Г.18); симметрия K(θ+π) = −K(θ); независимое
   интегрирование потокосцепления по уравнению (Г.13); сходимость по сеткам;
   условие (7); работоспособность при отказе аналитического метода (п. 5.1.5).

Кабельный блок в самопроверке не участвует: в эталонных примерах стандарта нагрузка
уже задана полным сопротивлением.

## Нормативная база

- **ГОСТ Р 58669-2019** (+ Поправка ИУС 6–7, 2020) — время до насыщения, классы P/PX/TPX;
- **ГОСТ Р 71879-2024** — время до насыщения, классы 5PR/10PR/TPY/TPZ/TPE, циклы АПВ;
- **ГОСТ Р 71403-2024** — методика выбора ТТ;
- **ГОСТ Р 70507.1-2024**, **ГОСТ Р 70507.2-2024** — общие ТУ на трансформаторы тока;
- **ГОСТ 7746-2015** — ТУ на ТТ прежних выпусков;
- **РД 153-34.0-35.301-2002** — проверка эксплуатируемых ТТ (все классы напряжения, включая 6–10 кВ);
- **ПУЭ** — требования к выбору и применению ТТ.
