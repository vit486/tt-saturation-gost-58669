# ⚡ Калькулятор времени до насыщения трансформаторов тока

Веб-приложение для проверки измерительных трансформаторов тока (ТТ) на насыщение в переходных режимах короткого замыкания в соответствии с **ГОСТ Р 58669-2019**.

## 📖 Теоретическая справка
Расчет выполняется аналитическим методом (п. 5.1 ГОСТ Р 58669-2019). Алгоритм определяет параметр режима $A$ и вычисляет время до насыщения $t_{нас}$ с учетом или без учета остаточной магнитной индукции ($K_r = 0.86$ для класса точности P).

Основные формулы:
1. $z_{2\Sigma.ном} = \sqrt{(R_2 + z_{н.ном} \cos \varphi_{ном})^2 + (X_2 + z_{н.ном} \sin \varphi_{ном})^2}$
2. $A = \frac{I_{1.ном} \cdot K_{ном} \cdot z_{2\Sigma.ном}}{I_{КЗ} \cdot z_{2\Sigma}}$
3. $t_{нас} = T_p \cdot \ln \left( \frac{\omega \cdot T_p + 1}{\omega \cdot T_p + 1 - A \cdot (1 - K_r)} \right)$

> Если знаменатель под логарифмом $\le 0$, насыщение в переходном процессе не происходит.
