# ⚡ Проверка трансформаторов тока (насыщение при КЗ)

Веб-приложение для проверки и выбора трансформаторов тока (ТТ) для релейной защиты:
расчёт времени до насыщения при коротких замыканиях по **ГОСТ Р 58669-2019**
с автоматической самопроверкой по эталонным примерам стандарта, динамическими
графиками и формированием отчёта в Word.

Разворачивается на Streamlit Community Cloud прямо из этого репозитория.

**Текущий релиз: 1.3 (22.10.2026)** — добавлен графический метод по паспортным данным.

## Реализованные методы

| Метод | Раздел ГОСТ | Как считается | Область применимости |
|---|---|---|---|
| Аналитический | 5.1 | формулы (3), (6) | t_нас ≥ 15 мс (п. 5.1.7), A·(1−K_r) > 1 (усл. 8) |
| Графический по паспортным данным | 5.2, приложение Б | численное решение уравнения K_п.р(t) = A·(1−K_r) по формуле (Г.15) с минимизацией по начальной фазе θ | без ограничений; **является определяющим** |

## Главные формулы

Оба метода решают одно уравнение переходного процесса (п. Г.6.2):
A·(1 − K_r) = K_п.р(t_нас)

**Параметр режима A** (формула 9):
A = ( I1ном · Kном · z2Σном ) / ( Iкз · z2Σ )
zн.ном = Sном / I2ном²
z2Σном = √( (R2 + zн.ном·cos φном)² + (X2 + zн.ном·sin φном)² )        (10)
z2Σ    = √( (R2 + Rн.факт)² + (X2 + Xн.факт)² )                        (11)
cos α  = ( R2 + Rн.факт ) / z2Σ                                        (12)

**Аналитический метод** — формулы (3)/(6):
t_нас = T_p · ln( ω·T_p / ( ω·T_p + 1 − A·(1 − K_r) ) )

> **Важно:** «+1» присутствует **только в знаменателе**.
> Контрольный пример стандарта (Приложение В, п. В.1.1.8):
> `t(3) = 0,128 · ln( 314·0,128 / ( 314·0,128 − 5,785 + 1 ) ) = 16,22 мс`

**Графический метод** — коэффициент переходного режима по формуле (Г.15):
K_п.р(t) = sin α · cos θ · e^(−t/T_p)
         + cos α · cos θ · ω·T_p · ( 1 − e^(−t/T_p) )
         − sin( ω·t + α + θ ) + cos α · sin θ
t_нас:  K_п.р(t_нас) = A·(1 − K_r),  минимум по θ ∈ (−90°, +90°)

Универсальные характеристики приложения Б построены именно по этой формуле для θ,
при которых t_нас наименьшее (п. Г.3.7), поэтому приложение решает уравнение численно
вместо снятия значений с чертежей — это исключает погрешность чтения графиков
и снимает ограничение на диапазон T_p.

## Достоверность расчётов

Расчётное ядро проверяется автоматически (вкладка «🧪 Самопроверка»):

1. **Аналитический метод** — воспроизведение эталонных примеров ГОСТ Р 58669-2019
   (Приложение В, В.1.1–В.1.3, с учётом Поправки ИУС 6–7, 2020):

   | Пример | A эталон | A расчёт | t эталон | t расчёт |
   |---|---|---|---|---|
   | В.1.1 КЗ(3) | 5.785 | 5.785 | 16.22 мс | 16.22 мс |
   | В.1.1 КЗ(1) | 3.418 | 3.418 | 7.87 мс | 7.87 мс |
   | В.1.2 КЗ(3) | 5.564 | 5.564 | 15.42 мс | 15.42 мс |
   | В.1.2 КЗ(1) | 3.453 | 3.453 | 7.98 мс | 7.98 мс |
   | В.1.3 КЗ(3) | 8.000 | 8.006 | 24.50 мс | 24.50 мс |
   | В.1.3 КЗ(1) | 5.000 | 5.010 | 13.24 мс | 13.24 мс |

2. **Графический метод** — 8 проверок реализации формулы (Г.15):
   начальное условие K(0) = 0; точное вырождение в (Г.17) и (Г.18);
   симметрия K(θ+π) = −K(θ) (обоснование полноты перебора θ);
   **независимое численное интегрирование потокосцепления по уравнению (Г.13)**
   (расхождение ~1·10⁻⁷); сходимость по сеткам θ и t; корректность условия (7);
   работоспособность в случае, когда аналитический метод отказывает (п. 5.1.5).

### Почему результаты двух методов различаются

Аналитическая формула — приближение: член `−sin(ωt + α + θ)` в ней заменяется огибающей,
а начальная фаза принимается равной нулю. Численное решение находит действительно
наихудшую фазу θ (в эталонных примерах θ* = 5…36°), поэтому расхождение достигает
15–18 %. Стандарт сам указывает на это: п. 5.1.7 требует уточнять графическим методом
результат меньше 15 мс, а п. 5.1.5 направляет к графическому методу при A·(1−K_r) ≤ 1.

| Пример | t аналит. | t графич. | Отклонение |
|---|---|---|---|
| В.1.1 КЗ(3) | 16.22 мс | 16.55 мс | −2.0 % |
| В.1.1 КЗ(1) | 7.87 мс | 9.55 мс | −17.6 % |
| В.1.2 КЗ(3) | 15.42 мс | 15.12 мс | +2.0 % |
| В.1.3 КЗ(3) | 24.50 мс | 28.86 мс | −15.1 % |

## Нормативная база

- **ГОСТ Р 58669-2019** (+ Поправка ИУС 6–7, 2020) — время до насыщения, классы P/PX/TPX;
- **ГОСТ Р 71879-2024** — время до насыщения, классы 5PR/10PR/TPY/TPZ/TPE, циклы АПВ;
- **ГОСТ Р 71403-2024** — методика выбора ТТ;
- **ГОСТ Р 70507.1-2024**, **ГОСТ Р 70507.2-2024** — общие ТУ на трансформаторы тока;
- **ГОСТ 7746-2015** — ТУ на ТТ прежних выпусков;
- **РД 153-34.0-35.301-2002** — проверка эксплуатируемых ТТ (все классы напряжения,
  включая 6–10 кВ);
- **ПУЭ** — требования к выбору и применению ТТ.
